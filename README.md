# AllergiScan 🛡️

AllergiScan is a premium, high-performance ingredient safety scanner designed to help you identify potential allergens in cosmetic and skincare products instantly.

## ✨ Features

- **Real-time Camera Scanning**: Instant OCR detection of ingredient labels.
- **Multi-language Support**: Seamlessly recognizes English, Thai, and Chinese (Simplified/Traditional) text.
- **Personalized Safety Profiles**: Save your specific allergens and get instant warnings when they are detected.
- **Premium Design**: A modern, responsive interface with a sleek teal-green aesthetic and smooth animations.
- **Historical Tracking**: Keep a log of your scanned products for quick reference.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jeffreyspirit/AllergiScan.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to see the application.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **OCR**: [Tesseract.js](https://tesseract.projectnaptha.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
